# v0.3.5 发布审查

审查日期：2026-09-12。基线：`4bf7091`，范围为当前未提交变更及新增文件。

## 本次修复

1. **安装版启动失败**：通过 `pyinstaller` 控制台入口打包时，spec 求值阶段尚未将项目目录加入模块搜索路径，`collect_data_files` 跳过本地策略包。生成的运行时在导入时缺少 `query_strategies.json`。改为基于 `SPECPATH` 显式收录资源，并在发布流水线上增加打包运行时启动和订单恢复检查。
2. **残留 Chrome 误匹配**：清理逻辑原先将配置目录插入 PowerShell 通配表达式，既不能安全处理单引号、方括号，也会匹配相似路径。改为通过环境变量传值、转义正则并匹配完整参数；Windows 实际匹配测试使用替身进程验证，不终止真实进程。
3. **订单核对日志误报与姓名泄露**：原报告用“已读到”与期望值比较，将正确字段列为差异；乘客不一致时会输出完整名单。改为显式比较字段，仅列出失败项，名单以人数和一致性结果表示，摘要屏蔽期望和实际姓名。诊断脚本同步修正字符串名单解析及报告脱敏。
4. **打包冒烟过期**：导航与配置版本断言仍对应旧界面和旧协议，更新为五个导航页面、配置版本 2，并验证运行时与应用版本一致。
