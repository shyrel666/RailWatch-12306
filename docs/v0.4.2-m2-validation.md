# v0.4.2 M2 实现与验证记录

日期：2026-09-23。范围：C2 托盘、退出与更新保护。工作区原有 M0／M1、订单与偏好修复保持未提交状态；M2 在其上增量修改。

## 实现

- 设置页用 `savePreferences` 局部补丁保存 `close_to_tray`。主窗口关闭时重新读取权威偏好；启用后首次说明后台运行，再隐藏窗口。托盘显示状态，可显示窗口、请求停止监控或退出。创建托盘失败时进入退出流程。
- 主进程拦截窗口关闭与 `before-quit`，统一执行退出准备。活动任务及未完成订单需用户确认；取消确认不触发停止。退出准备成功后才停止运行时、清理声音窗口与托盘并退出。
- 后端 `taskActivity` 读取任务、浏览器操作及未完成订单；`prepareShutdown` 在同一任务锁下关闭新任务准入。退出请求停止任务，最多等待 20 秒，释放受控浏览器并刷写订单遥测；超时返回错误并重新开放准入。安装要求无活动任务及未完成订单，安装前再次在后端锁内检查并保持门禁。
- 自动更新关闭 `autoInstallOnAppQuit`；下载提示在活动任务或未完成订单期间不弹出，主进程安装入口独立再检查。运行时曾意外中断时拒绝安装，提示重新启动后核对。
- 普通退出保留订单数据库；本地退出不会宣称取消官方订单。系统强制终止无法由应用保证延缓，恢复依赖已有持久化订单意图。
