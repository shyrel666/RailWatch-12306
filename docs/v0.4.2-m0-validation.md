- 现有偏好 IPC 支持省略主题的局部更新；新增托盘和置顶偏好数据字段，为后续阶段提供存储基础。

验证重点：通知补丁不重置主题；主题补丁保留托盘和通知；并发补丁都保留；保存失败后文件与服务一致；草稿损坏不影响已保存配置和待支付订单恢复；DPAPI 原有故障回归继续通过。

UI 与通知是两个独立原子文件，不提供跨文件全成全败事务；混合请求中 UI 写入失败时，先前通知提交可能已生效，需重新加载确认。该行为有专门故障测试，并写入公共契约。

本阶段不改查询页面适配、交易流程、窗口行为或通知发送行为，因此未重跑离线浏览器及安装包流程；没有执行真实账号查询、下单、支付或外部通知试发。应用版本未提升，未生成新的安装包。
