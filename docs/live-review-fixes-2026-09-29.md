# 2026-09-29 真实页面审查修复

针对当前 v0.5.0 工作区修复候补页面适配、彩排结论、停止行为及订单恢复。保留原有未提交改动；本次没有创建、支付或取消真实订单，也没有修改正式配置。

## 修复后的行为

1. **候补成人票种与勾选**：官方候补页普通成人标签仅显示姓名时，从该乘客 DOM 属性读取票种及姓名前缀；不向 Python 返回证件和令牌字段。姓名、标签和票种字段必须一致，学生／儿童、字段缺失或冲突仍拒绝自动选择。通过对应标签操作自定义复选框，再回读实际名单。
2. **候补待支付识别**：在已匹配订单卡片的专用支付控件内，允许官方倒计时结构。订单号、行程、席别和乘客仍全部参与核对；不点击支付，不借用其他卡片或隐藏控件的证据。
3. **彩排结论**：定时任务缺少时钟判断证据时总结论为“有风险”。个人中心未提供票种的本人记录显示警告，不能直接当成人通过。离线候补演练改为无成人标签、带票种元数据的乘客结构，并使用带倒计时的待支付卡片。
4. **停止行为**：停止后不再发起确认点击；已发出的提交不能撤回。实际浏览器取消守卫在提交／确认期间中断时，保存“未知”结果及提交标记，禁止重放，保留页面供人工处理。提交前停止则明确记录尚未提交。
5. **恢复核对**：已绑定订单号可在普通未出行／历史、候补待兑现／已处理标签中有限查找。每个标签最多等待5秒，仍需完整订单证据；不改查询日期、不翻页。未绑定订单号不自动查历史；排队或确认弹窗未结束时保留原页面。

这次复验完成了有效登录下的完整只读彩排，不证明真实候补创建、预付款、生效至兑现、支付后的完整本地同步及断网／重启恢复已通过。当前账户没有候补订单，候补交易页面的适配以当天官方公开模板和脱敏本地回归验证。生产构建覆盖 Electron／前端；本次未重新生成或安装 Windows 安装包。
