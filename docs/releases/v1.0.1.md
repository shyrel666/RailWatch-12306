# RailWatch 12306 v1.0.1

安全加固与稳定性修复版本。

## 安全

- **ChromeDriver 下载与校验加固**：仅在内置对应版本和平台的 SHA-256 摘要时才允许使用国内 `npmmirror` 镜像下载并校验摘要；其他版本直接从 Google 官方 HTTPS 地址下载（禁止重定向）并校验响应对象完整性（`x-goog-hash` MD5）。下载过程改为流式写入临时文件并限制压缩包与驱动体积，安装前核对驱动 `--version` 的完整版本号一致。
- **收紧渲染器开发地址限制**：打包后的桌面端忽略 `VITE_DEV_SERVER_URL`；开发模式下也仅允许本机回环地址（`127.0.0.1`、`[::1]`、`localhost` 且不含凭据）。
- **收紧发布工作流权限**：GitHub Actions 发布工作流默认权限改为 `contents: read`，仅发布步骤授予 `contents: write`。

## 修复

- **官方预填加速开关持久化**：修复 `prefill_enabled` 未随行程配置保存，导致关闭官方预填加速后重启恢复开启的问题。
- **订单、预填与已购行程核对加固**：
  - 统一使用独立站名边界判断出发站与到达站顺序，避免“北京”匹配到“北京南”导致站序误判。
  - 收紧官方预填确认弹窗回读：必须完整读到乘车人姓名、对应席别且全部为成人票种，缺列或空项时不放行。
  - 启动前已购行程检查保留“未完成订单”与“未出行订单”任一页签已识别到的冲突证据，另一页签读取异常时不再丢弃冲突提醒；未完成订单未能核实时明确记录原因。
- **登录与浏览器状态同步**：
  - 自动提交或自动候补任务启动前，若保活检查返回未知状态，0.5 秒后复查一次；仍未确认登录有效时重置登录状态并提示人工确认。
  - 销毁或关闭受控浏览器时同步重置登录与查询就绪状态，避免界面残留过期就绪状态。
- **本地数据清理与错误提示**：
  - 清除本地数据时，若 Electron 窗口设置、会话数据/缓存或更新缓存清理失败，改为明确报告未清除项并提示重试。
  - 将待清理目录清单迁移至数据目录父级隐藏文件（POSIX 下同步 `fsync` 父目录），提高异常中断后残留目录恢复清理的可靠性。
  - 订单中心读取历史失败时显示错误提示并支持点击刷新重试，不再误展示空白列表或陈旧分页。
- **macOS 钥匙串与运行稳健性**：
  - macOS 钥匙串读取失败或被拒时，保护已有密钥标记与通知渠道配置不被后续非密钥修改意外覆盖，且未改动密钥时不重复写入钥匙串。
  - 修复已保存行程配置包含无效字段时导致加载异常的问题（安全回退默认行程并记录警告）。
  - 修正起售提醒刷新官方起售时间后的当前时间基准判断；修复外部推送遇到 HTTP 错误时未及时关闭响应句柄的问题。
  - 移除未使用的 `zod` 依赖，Windows 打包脚本调用 `npm version` 时增加 `--allow-same-version`，诊断脚本避免输出敏感乘车人信息。
