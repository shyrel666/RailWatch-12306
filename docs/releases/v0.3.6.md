# RailWatch 12306 v0.3.6

本版本修复 v0.3.5 安装版在「环境检查」时报 `No module named 'selenium.webdriver.chrome.options'`、无法就绪的问题。

## 更新内容

- selenium 4.44 起把浏览器子模块（`chrome.options` 等）改为运行时懒加载导入，PyInstaller 静态分析无法看到这些依赖，因此 v0.3.5 安装包缺少该模块：应用启动正常，点「环境检查」或启动监控时才报错。打包时现在强制收集全部 selenium 子模块。
- 构建期新增断言：关键 selenium 子模块未进入打包产物时直接构建失败，避免再次发布坏包。
- Python 运行时启动时提前解析 selenium 懒加载导入；环境缺失时直接给出真实原因，而不是笼统提示未安装。

## 下载与升级

下载本页附件 `RailWatch-12306-0.3.6-x64.exe` 安装，或通过应用内检查更新升级。从 v0.3.5 升级后，环境检查即可恢复正常。
