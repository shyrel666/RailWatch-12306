RailWatch v0.3.0 补齐交易状态、订单证据和恢复流程，面向个人单账号、自动提交、人工核验及支付的使用方式。

- 优先检查全部目标车次的现票；明确售罄并核对无订单后，立即进入首选候补路径。
- SQLite 保存提交意图和订单证据，重启后可继续核对，未知提交不自动重放。
- 精确校验候补组合、席别、乘客与官方截止时间选项，区分待支付、生效和兑现。
- 完整北京时间起售配置、单调时钟调度、防休眠与恢复暂停，外部通知异步执行。

升级后，旧版仅含时分秒的定时配置需要补全起售日期；自动化需要明确车次、席别和乘客姓名。源码运行要求 Python 3.10 及以上。

验证通过：Python 145 项、Electron 30 项、React 75 项、Chrome 离线回归 22 项，生产构建及打包运行时恢复测试通过。1000 次本地短期限定时演练的唤醒误差 P95、P99 均为 17 毫秒，这不代表官方查询或下单时延。

**交易自动化仍为实验性功能。尚未进行真实账号下单与支付验收，不保证抢票成功或候补兑现。核验和支付必须由用户在官方页面完成。**
