# v0.6.0：macOS 安装包

应用、Python 运行时及 Windows / macOS 安装包版本统一为 0.6.0。

## 本次更新

- **macOS 安装包**：新增 Apple Silicon（`arm64.dmg`）与 Intel（`x64.dmg`）两个安装包，内置 Python 运行时，最低 macOS 12。打开 DMG 后把 RailWatch 12306 拖入「应用程序」即可，仍需安装 Google Chrome。
- **未经 Apple 公证**：当前 macOS 安装包为 ad-hoc 签名。首次打开时系统会提示无法验证开发者，请到「系统设置 → 隐私与安全性」点击「仍要打开」（macOS 15 起右键「打开」已不能绕过），或在终端执行 `xattr -dr com.apple.quarantine "/Applications/RailWatch 12306.app"`。
- **macOS 更新方式**：应用内检查到新版本后，主按钮变为「前往下载」，打开对应的 Release 页面手动下载新 DMG 覆盖安装，配置与订单记录会保留。Windows 仍为自动下载、点击「立即重启安装」。
- **通知凭据与钥匙串**：macOS 上邮箱授权码、Server 酱 Key 与企业微信 Webhook 保存在系统钥匙串的单个条目中，配置文件只记录哪些字段已设置。凭据在启动后由后台读取，钥匙串授权框不会阻塞应用启动。手动升级后首次启动可能弹出一次授权框（发起程序显示为 `railwatch_runtime`），选择「始终允许」即可；拒绝只会停用外部通知。清除本地数据时会一并删除该钥匙串条目。
- **macOS 体验适配**：复制、粘贴、全选与 Cmd+Q 可用，Cmd+Q 与 Windows 退出一样会先检查活动任务和未完成订单；关闭到托盘后菜单栏显示图标；紧急提醒时 Dock 图标跳动；强制退出会结束运行时启动的 chromedriver 与受控 Chrome；ChromeDriver 自动下载到数据目录，也能识别装在用户目录下的 Chrome。
- **更新提示**：最新版本暂时只提供了另一平台的安装包时，显示「最新版本暂未提供本平台安装包，请稍后再检查」，不再提示更新源不可访问。
- **发布流程**：Windows 与两种 macOS 架构由同一工作流并行构建，各自验证签名与最终安装包后，由一个发布任务统一上传，`latest-mac.yml` 同时包含两种架构。

## 下载与升级

| 平台 | 下载 |
| --- | --- |
| Windows 10/11 | `RailWatch-12306-0.6.0-x64.exe`，或使用应用内检查更新 |
| macOS，Apple M 系列芯片 | `RailWatch-12306-0.6.0-arm64.dmg` |
| macOS，Intel 芯片 | `RailWatch-12306-0.6.0-x64.dmg` |

不确定芯片类型时，打开「苹果菜单 → 关于本机」查看「芯片」一栏。Windows 用户的安装、配置与更新方式不变。

## 验证与使用边界

发布前本地验证通过：Python 单元测试 480 项、Electron 测试 120 项、前端测试 263 项，类型检查及生产构建通过；Windows 安装包与冻结运行时冒烟通过。macOS 安装包只有在 GitHub macOS 构建机上通过签名校验、使用临时钥匙串的运行时冒烟和 Electron 应用冒烟后才会上传。

macOS 版本按 [macOS 真机验证清单](https://github.com/shyrel666/RailWatch-12306/blob/v0.6.0/docs/release-qa.md) 验收；Developer ID 签名、Apple 公证与应用内自动安装计划在后续版本提供，启用后需要手动安装一次签名版。Intel 版依赖 GitHub 的 Intel 构建机（GitHub 公告支持至 2027 年 8 月），之后的安排会提前公告。

非 12306 官方产品，不保证购票或候补成功；自动候补仍为实验性功能，登录核验和支付由用户在官方页面完成，实际订单状态以官方页面为准。
