RailWatch v0.3.2 新增极简「关于」页面。

- 侧边栏新增「关于」入口，页面隐藏顶部操作栏，只保留品牌、版本号和必要操作。
- 检查更新按钮与 GitHub 仓库快捷入口。
- 项目链接：GitHub 仓库、发布与下载、问题反馈、更新日志和 MIT 许可证，点击后在系统默认浏览器中打开。
- 底部展示运行环境（Electron／Chromium／Node.js）和一句使用边界说明。
- 安全限制：外部链接桥接只允许 `https://github.com` 域名，其他协议和域名会被拒绝。

交易自动化仍为实验性功能；真实账号下单与支付尚未验收，核验和支付必须由用户在官方页面完成。
