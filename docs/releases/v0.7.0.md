# RailWatch 12306 v0.7.0

## 新增功能

- 自动候补新增一等座、硬座、软座、硬卧、软卧，与二等座合计支持六种席别。
- 候补截止兑现时间使用官网实际选项，尚未提交的方案可重新选择后继续。
- 新增“接受新增列车”设置，支持按日期和出发时段配置，并在提交、恢复与兑现核对时保留原条件。
- 支持读取官网候补预估成功率与预付款金额。
- 自动候补可处理已识别的静音车厢提示、截止兑现时间与规则确认。
- 提示音支持多种内置音效、自定义音频导入与试听。

## 修复

- 修复部分席别单元格中的候补入口无法识别，以及进入付款页后未能及时绑定官方订单号的问题；重启后继续核对原订单，避免重复提交。
- 修复官网截止兑现时间标签为空时无法选择选项的问题，兼容城市级站名和旧版截止时间配置。
- 修复提交前的表单错误被误判为提交结果待核对的问题，准确提示失败步骤。
- 修复候补确认按钮被遮挡或尚未就绪时的点击失败；读取预估成功率不再阻塞候补提交。
- 修复新增列车时段包含其他候补日期时导致当前方案中止的问题。
- 修复行程加载期间默认值可能覆盖已保存乘客、席别或车次的问题。
- 修复紧急提醒循环提示音无法播放的问题，避免自定义音频重叠或截断，更换音频后清理旧文件。
- 修复更新站码时干扰运行中查询的问题，减少读取查询记录时不必要的磁盘写入。
