# RailWatch 12306 v1.0.0 正式版

**首个正式版。** 此前的 0.x 均为早期版本，自本版起版本号进入 1.x。

## 新增

- 定时自动提交任务开启了官方预填加速、但本次没有用上时（距起售不足 90 秒、时区或倒计时不符、预填入口不可用等），购票监控显示具体原因并说明到点后按常规余票查询执行；运行复盘保留这条原因。
- 行程设置中，本机时区不是北京时间时，官方预填加速开关下直接提示“预填不会启用”。
- 记住窗口大小、位置和最大化状态，下次启动时恢复；显示器变化后窗口超出屏幕时自动收回可见范围。
- 导出日志对话框新增磁盘与卷列表（Windows 为各盘符，macOS 为根目录、主目录和已挂载的卷），并支持直接输入 `D:` 这样的盘符跳转。
- ChromeDriver 下载优先使用 npmmirror 国内镜像，镜像不可用或下载内容有问题时自动回退官方源；下载的驱动确认能运行且主版本与本机 Chrome 一致后才替换现有驱动。
- 紧急提醒更不容易错过：开启桌面通知时，Windows 上紧急事件的系统通知停留在屏幕上直到手动关闭（此前几秒后收进通知中心），任务栏图标显示红色角标；macOS 上程序坞图标显示角标，通知设置中说明如何让通知留在屏幕上。回到窗口或停止提醒后，角标和这条通知一并撤掉；新的紧急提醒会替换上一条通知。

## 变更

- 启动不再等待网络连通性检测：网络和 12306 状态先显示“检测中”，后台检测完成后更新。运行信息由每 30 秒刷新改为每 3 分钟刷新，窗口隐藏时暂停。
- 最小窗口尺寸由 1180×720 调整为 840×580。
- 启动画面统一为深色，结束后切换到所选主题；窗口标题栏和背景跟随所选主题。
- Windows 安装包内的运行时由单文件改为目录形式，启动时不再解压到临时目录，并停用 UPX 压缩。
- 安装包内置的 Python 运行时统一升级到 3.14（此前 Windows 为 3.10，macOS 为 3.12）。
- macOS 读取 Chrome 版本时不再需要启动 Chrome。
- 移除从未接入桌面端的浏览器指纹伪装和拟人操作代码；受控浏览器保持真实的 UA、分辨率、时区、Canvas 和 WebGL。

## 修复

- 起售前的登录复核只因网络慢或检查超时而无法确认时，不再直接停止定时任务：间隔 5 秒最多重查 2 次，且都在起售前最后 10 秒之前完成。登录确已失效、重查后仍无法确认或剩余时间不够重查时，照常停止并提醒。
- Chrome 下载与手动驱动指引适配国内网络环境：将环境检查与安装指引中的 Chrome 官方下载链接改为 `https://www.google.cn/chrome/`，自动下载失败时优先指引从 `npmmirror` 国内镜像手动下载对应版本的 ChromeDriver。
- macOS 更新直链匹配芯片架构与 Rosetta 转译提醒：点击“前往下载”时直接打开匹配架构的 `.dmg` 安装包链接而非通用 Release 页面；通过 `app.runningUnderARM64Translation` 识别在 Apple Silicon 上转译运行的 Intel（x64）版本，自动将目标更新包导向 Apple Silicon（`arm64`）原生安装包，并在启动通知、关于页和更新面板中提醒用户更换原生版本。
- macOS 菜单栏图标、文案与菜单交互：新增单色透明模板图标 `trayTemplate.png`（18×18）与 Retina `@2x` 图标 `trayTemplate@2x.png`（36×36）并随安装包打包，自动适配系统深浅色反色与高分屏；区分桌面平台文案，macOS 显示“关闭到菜单栏”与“显示窗口”提示，且菜单栏图标仅绑定右键/左键弹出菜单交互，不再绑定双击或单击拉起窗口。
- 统一本地数据目录、完整清除与卸载清理选项：将 Electron `userData`（含 `window-state.json`、`.updaterId` 及 Chromium 存储）收敛至应用数据根目录下的 `electron` 子目录并自动迁移旧版遗留的窗口状态与 `.updaterId`；“清除本地数据”在保留 Electron 活动句柄稳定的前提下，一并清理 `window-state.json`、浏览器会话与缓存、全部 `railwatch.*` `localStorage` 键及更新缓存目录（`railwatch-12306-electron-updater`）；Windows 安装包的交互式卸载流程新增可选“同时删除本地配置、12306 登录数据与更新缓存”复选框（并支持 `--delete-app-data` 参数，自动更新场景跳过删数据）；同步在 [PRIVACY.md](https://github.com/shyrel666/RailWatch-12306/blob/main/PRIVACY.md) 补全所有本地目录、`localStorage` 键及清理与卸载说明。
- Windows 上已下载的更新安装包被“清除本地数据”、磁盘清理工具或安全软件删除后，不再出现点击安装反复报错、又无法重新检查更新的情况：更新面板提示重新检查，检查后重新下载。清除本地数据后更新状态回到“尚未检查更新”。
