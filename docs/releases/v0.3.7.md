# RailWatch 12306 v0.3.7

本版本将应用内弹窗统一为主题化样式，并修复自动提交在官方确认弹窗处挂起、等待人工确认的问题。

## 更新内容

- 弹窗去原生：清除本地数据、关闭浏览器、结束本次核对、自动提交启动等主进程确认，以及"新版本已下载、是否立即重启安装"提示，全部改为跟随明亮/深色主题的应用内对话框。确认闸门仍保留在主进程，渲染层只负责展示与回传选择；导出日志的"另存为"对话框与系统通知保持原生。
- 自动提交模式下，官方「请核对以下信息」确认弹窗出现后直接点击"确认"提交。弹窗打开时乘客会在背景页和弹窗表格各被读一遍，原有的弹窗内二次核对必然失败，导致弹窗挂起等待人工确认而错失抢票窗口；点击"提交订单"前的完整回读核对保持不变。

## 下载与升级

下载本页附件 `RailWatch-12306-0.3.7-x64.exe` 安装，或通过应用内检查更新升级。从 v0.3.6 升级后，自动提交将直接完成官方确认，弹窗不再挂起。
