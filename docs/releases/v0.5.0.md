# v0.5.0：起售彩排与实战复盘

发布日期：2026-09-29。源码、Windows 安装包与自动更新版本统一为 0.5.0。

## 新增功能

- 在购票监控页运行起售彩排，逐项检查配置、起售时间、登录、乘车人、车次席别、时钟、唤醒与提醒渠道，并提供修复入口。
- 在隔离的本地页面演练普通订单、候补、座位偏好与截止时间核对；不会创建真实订单。
- 报告给出“就绪／有风险／会失败／已取消”，配置改变后提示过期；最近 20 份脱敏报告保存在本地。
- 订单中心新增起售复盘，展示已记录的阶段耗时、准备余量、查询中位数与彩排预测；缺失记录明确留空。
- 定时任务开始等待前可自动彩排，默认关闭，可在系统设置开启，要求距起售超过 15 分钟；停止任务会同时取消彩排。
- 支持清除本地彩排记录，保留订单与实战复盘；卡片采用紧凑布局，详细检查可在弹窗查看。
- 候补截止增加常用时间下拉选项，同时保留完整日期时间输入；实际提交前仍需匹配官方页面选项。
- 修复冷启动和网络检查较慢时，正常运行时可能被十秒就绪超时提前终止的问题。

## 使用边界

官方乘车人列表不显示账号本人的票种，彩排对本人行按成人处理并给出说明，不计为风险；其他乘车人不能凭姓名或核验通过推断成人，普通订单会继续在下单页回读，自动候补要求明确的成人证据。预通过和待核验等状态需要根据证件情况核对。

预测只解释本机路径耗时，不预测余票或成功率。本地脚本耗时不含官方页面加载和处理。提醒试发默认关闭；自动彩排不试发。

手动彩排与监控等浏览器操作互斥，有未决订单时不可运行；两次间隔至少两分钟，起售前不足五分钟拒绝运行。重启后恢复的历史报告会保守提示过期，需要重新彩排。

## 验证范围

真实会话已验证登录失效保护路径；有效登录下的完整彩排与真实多页乘车人列表验收尚未完成。本地回归不代表官方交易页面验收通过，详见 [验证记录](https://github.com/shyrel666/RailWatch-12306/blob/v0.5.0/docs/v0.5.0-validation.md)。
