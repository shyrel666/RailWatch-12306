RailWatch v0.3.1 是一次界面与品牌更新，默认主题改为浅色，并替换了应用图标。

- 默认浅色主题：首次运行或未保存过主题偏好时直接进入浅色界面，仍可在状态栏切换深浅主题。
- 新品牌标识：应用图标更新为平面单色 R 字标；侧边栏品牌区改为几何小写字标 `railwatch 12306`。
- 版本号移动到窗口底部状态栏，品牌区保持图标加字标。

安装本版本后，桌面快捷方式、开始菜单和任务栏图标会更新为新图标。如果 Windows 仍显示旧图标，属于系统图标缓存，可注销或重启资源管理器后恢复。

本次没有交易流程改动，交易自动化仍为实验性功能；真实账号下单与支付尚未验收，核验和支付必须由用户在官方页面完成。
