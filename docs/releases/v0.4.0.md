# RailWatch 12306 v0.4.0

本版本修复自动确认点击过早、提交后误报未识别订单，以及系统设置中登录检查缺少反馈的问题。

## 更新内容

- **自动确认**：按已配置目标核对订单后，等待官方确认按钮真正启用，再自动点击。处理弹窗延迟、按钮重绘和未送达点击，避免在回执不明确时重复提交。
- **提交结果**：识别官方处理中、排队提示及随后出现的待支付页面。只有订单号及行程、乘客、席别匹配时才显示待支付；核对成功后清除旧的人工核查提示。
- **登录检查**：点击后显示检查进度、登录成功或失败原因。浏览器已关闭、会话失效、网络异常不再表现为无反馈。

## 下载与升级

下载本页附件 `RailWatch-12306-0.4.0-x64.exe`，退出旧版后安装；也可使用应用内检查更新。`latest.yml` 和 `.blockmap` 附件供自动更新使用。

## 验证范围

完成 Python、Electron、React 测试、TypeScript 类型检查及本地 Chrome 订单流程回归，覆盖官方按钮延迟启用、处理弹窗、待支付信息核对和登录检查反馈。Windows 发布流水线验证打包运行时启动与订单恢复。

自动化测试未执行真实账号下单或支付。核验及支付仍需在官方页面人工完成，实际订单状态以12306为准。
