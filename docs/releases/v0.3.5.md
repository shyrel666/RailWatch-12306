# RailWatch 12306 v0.3.5

本版本更新查询策略、订单恢复、浏览器异常恢复和桌面界面，并修复发布审查发现的进程匹配及日志问题。

## 更新内容

- 仪表盘、行程设置、监控与事件面板重新布局，支持明亮、深色和跟随系统主题。
- 前后端共用查询策略；保留原有自定义间隔，支持服务端限频等待，避免把旧表格或迟到响应当成新结果。
- 批量读取余票，准确区分高级软卧等席别，支持纯数字车次；提交前按实际站点、带票价席别和乘客信息核对。
- 改善确认回执丢失后的订单核对，恢复任务使用跨进程锁；结果不明记录可由用户确认结束本地核对。
- Chrome 窗口关闭及 Python 运行时退出后可恢复；清理残留 Chrome 时精确匹配配置目录，支持含空格、单引号和方括号的路径。
- 日志导出包含暂停期间的保留事件，订单回读报告不再误报已匹配字段，也不输出期望或实际乘客姓名。
- 修复查询策略资源遗漏导致安装版启动失败的问题，发布流水线在上传前验证打包运行时启动与订单恢复。

## 下载与升级

下载本页附件 `RailWatch-12306-0.3.5-x64.exe` 安装，或通过应用内检查更新升级。安装包、差分校验文件和 `latest.yml` 由同一次 Windows 构建生成。
