# v0.4.2 M4 行程配置验证记录

日期：2026-09-23。范围：C4 路线与车次、C5 席别与乘客、C6 草稿与启动摘要。

## 已实现

- 站码源按中文、拼音、简拼检索，缓存可显式刷新；网络失败时可用已有缓存，手动输入仍可使用。最近路线与按路线收藏保存在独立文件，车次顺序与执行顺序一致。当前路线和日期的结构化查询结果可用于选择实际车次。
- 单一席别能力表分别表示查询、普通提交和候补支持；页面夹具覆盖已识别的硬座、软座、卧铺等普通提交选择。自动交易仅接受明确支持的席别；不限席别仍可用于查询。
- 不再把手动乘客姓名标为成人。可在受控浏览器空闲时读取当前官方页面可见的乘客候选；不明票种、同名和学生／儿童候选不能直接用于自动交易。提交前仍要读取官方页面乘客及成人票种并核对。旧姓名配置可加载。
- 编辑草稿与正式保存配置、运行任务快照分别管理。草稿原子保存并以递增修订防止旧写入覆盖；损坏草稿归档后回退。启动摘要使用确认时的配置快照和日期，运行中编辑仅影响下次任务。

## 验证证据

`tests/test_m4_trip_choices.py`、`tests/test_m4_drafts.py`、`tests/test_orders.py`、TripSetup 与 Monitor 的 React 测试覆盖缓存、路线隔离、草稿持久化、启动快照和乘客边界。`tests/order_browser_smoke.py` 的本地 Chrome 页面夹具覆盖席别及未知／非成人乘客拦截。`tests/trip_order_ui_smoke.py` 检查 1440×900 与 1180×720 的行程页面。完整回归数字见 M6 记录。

## 实测边界

乘客读取仅针对当前受控浏览器页面中可见的候选；未实现无页面证据的乘客管理页自动导航。证件摘要仅在页面提供且符合脱敏格式时显示，同名项按姓名禁止自动选择；不能把脱敏摘要当作身份唯一证明。真实账号的站码源、乘客列表和交易页面仍需人工检查。学生、儿童自动化以及候补生效后的周期性复查不在本版范围。
