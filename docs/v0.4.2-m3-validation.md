# v0.4.2 M3 实现与验证记录

日期：2026-09-23。范围：C3 通知设置、试发与结果反馈；M4–M6 待实施。

## 实现

- 系统设置页提供桌面通知、循环声音、窗口置顶、Server酱、SMTP 邮件及企业微信配置。通知更新只发送 `notification_settings` 补丁，不覆盖主题或托盘。密钥输入留空表示保持，输入新值表示替换，删除按钮发送 `null`；页面只读取“已配置”标记。
- 每种事件独立选择外部渠道：发现余票、需要核验、待支付、候补生效、候补兑现、购票成功。旧文件缺少选择时沿用全部外部渠道的既有行为。后端校验补丁字段、类型、端口和事件选择。
- 主进程在提醒执行处使用已保存偏好；桌面通知和声音可独立开启。关闭声音立即终止循环。统一 `event_id` 抑制同一紧急事件重复弹出。
- `testNotification` 只发送固定内容，不包含乘客或行程信息；前端有未保存编辑时拒绝试发并提示先保存。`notificationStatus` 提供各渠道最近成功／失败及时间；禁用和未配置由试发返回。
- 外部发送使用最多 3 个工作线程和 12 个在途任务位，渠道独立使用已有网络超时，事件键去重。队列满返回明确状态，不为每个事件创建新线程。错误和服务端失败回执不写入日志；已有 Windows DPAPI 保护及解密失败恢复路径保持。
