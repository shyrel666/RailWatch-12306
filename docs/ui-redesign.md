# 桌面界面与主题重设计

界面以当前行程和下一步操作为中心，视觉主题为「发车牌」：暖纸色／墨色底，靛蓝表示可操作，信号灯三色表示状态，首页和监控页顶部用一块在两套主题下都保持深色的发车牌展示路线、车次和时间。侧栏可以折叠，日志从常驻第三栏改为按需打开的抽屉，系统信息集中在设置页。

## 视觉语言

- 颜色各司其职：靛蓝（`--accent` 填充，`--accent-text` 文字）只用于按钮、选中项、链接和焦点；`--success`／`--warning`／`--danger` 只表达状态，分别对应可行／等待／停止，不用于操作按钮；琥珀 `--led` 只出现在发车牌的实时数字上。
- 中性色：明亮主题为 `#f4f3ef` 底、白色卡片；深色主题为 `#101113` 底、`#18191c` 卡片。卡片用 `--card-ring` 半透明描边，不再使用实线边框套边框。
- 发车牌（`DepartureBoard`）在两套主题下都使用深色底，内部 Ant Design 控件通过 `getBoardTheme()` 固定使用深色算法。下沿的虚线和两侧缺口取自车票撕口。
- 数字（时钟、倒计时、车次、查询次数）使用等宽或表格数字，跳动时不左右移动。等宽字体优先使用系统自带的 Cascadia Mono／SF Mono，缺失时回退 Consolas／Menlo。
- 正文 14px；页面标题 22px；辅助说明 12～12.5px，不小于 11px。

## 实现约定

- `src/lib/theme.ts` 定义两套语义颜色、发车牌主题及 Ant Design 配置，`theme.test.ts` 校验所有文字／底色组合的对比度不低于 4.5:1；`useThemePreference` 负责跟随系统、加载与保存偏好。CSS 变量应用于文档根节点，弹窗和下拉菜单使用同一套主题。
- 偏好文件支持 `system`、`light`、`dark`；已有明暗偏好继续有效，缺失或损坏的配置回退 `system`。本地浏览器缓存只用于首次绘制，Python 偏好文件为持久化来源；保存失败恢复原主题。
- 首页按未解决订单、人工操作、运行状态及准备阶段选择下一步，准备步骤以线路图形式展示。首页和监控页共用订单未解决判定；运行中继续使用任务启动时的配置快照。发车牌右侧依次显示：运行时长（运行中）、距定时开售（已设置定时）、出发日期。
- 行程设置保留全部原有字段，分为路线与乘客、查询策略、定时启动、自动化。首页可定位并打开相应分组；导航只滚动页内内容。
- 日志默认关闭，关闭时仍接收事件；筛选与暂停状态保留在当前会话。抽屉支持 Esc 和关闭后返回入口焦点。高优先级通知仍独立展示。抽屉以时刻表呈现：左列北京时间（完整日期在悬停提示中），中间竖线上的圆点按级别着色，信息类不再显示级别标签；顶部显示「实时接收中／已暂停」及待显示条数，级别筛选为分段控件。
- 系统设置顶部为吸顶的横向分组条（下划线标出当前分组，随滚动更新；点击后保持所选分组直到手动滚动），不使用与侧栏相同的竖排菜单样式；分组依次为环境与登录、外观、运行偏好、通知、本地数据、维护操作。环境检查以状态磁贴展示；主题以三张缩略图选择；通知分为本机提醒、外部渠道卡片（含最近发送结果）和「事件 × 渠道」勾选矩阵；清除数据放在红色危险区。
- 关于页顶部为深色品牌牌：图标、字标与标语，右侧等宽数字显示版本与更新状态，下沿为运行环境与检查更新；下方为「项目与文档」链接和「使用须知」。
- 网络、12306 与运行状态以信号灯形式放在侧栏底部，北京时间放在顶栏右侧；原底部状态栏取消。
- 窗口最小尺寸仍为 1180×720；小于 1280px 默认收起侧栏。保存与查询操作固定在表单底部，监控页的发车牌（含启动／停止）吸附在内容区顶部。

## 可重复的视觉检查

`scripts/review-ui.cjs` 使用 Playwright 和本机 Google Chrome，以模拟的 `window.railwatch` 桥接数据运行真实前端；不连接账号或真实订单。先启动 `npm run dev:renderer`，在另一个终端运行 `npm run review:ui`。

运行环境需要提供 Playwright 包，可以使用 `RAILWATCH_PLAYWRIGHT` 指向已有的 Playwright 模块目录；未设置时按 Node 标准规则加载 `playwright`。`RAILWATCH_PREVIEW_URL` 可指定 Vite 地址，默认 `http://127.0.0.1:5173`。Playwright 不属于生产依赖。

脚本检查全部六个页面在两套主题和三种尺寸下的 36 个组合：1180×720、1440×900、1920×1080。额外在 1180×688 验证长车次列表、长查询结果与异常信息，检查内容宽度及固定操作栏，并验证日志筛选、焦点恢复、订单定位和取消自动化确认。

输出位于 `build/ui-review/`：

- `dashboard-light.png`、`dashboard-dark.png`：首页明暗主题。
- `<宽度>-<light|dark>-<dashboard|trip|monitor|settings|about>.png`：页面尺寸矩阵。
- `monitor-running-dark.png`、`monitor-attention-dark.png`：运行与待处理订单。
- `log-drawer-dark.png`、`automation-confirmation-dark.png`：抽屉及确认弹窗。
- `stress-*.png`：最小可用高度下的长内容场景。
- `report.json`：尺寸测量、浏览器错误及模拟命令记录。

这些截图验证的是实际渲染器。真实账号、订单提交和打包安装程序未纳入此次视觉验收。
